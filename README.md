# AnchorTweaks

Small client-side Fabric mod that removes the respawn anchor use delay, allowing instant charge and explode interactions.

## Supported Versions

- Minecraft: `1.21.4` (range: `>=1.21.4 <1.22`)
- Fabric Loader: `0.16.5+`
- Java: `21`
